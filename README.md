# program-banners

자동화 프로그램 GUI 배너 자산. **`banners.json` 만 고치면 재빌드 없이 배너가 바뀐다.**

- 이미지를 바꿀 때는 **파일명에 날짜를 넣어 새로 올린다**(같은 이름 덮어쓰기는 캐시 때문에 반영이 늦다)
- 배너를 내릴 때는 `enabled` 를 `false` 로
- `click` 을 비워 두면 프로그램에 박힌 기본 링크를 쓴다(쿠팡은 프로그램마다 제휴 링크가 달라 비워 둔다)

규격: **920x160 · 2프레임 · duration 1000ms · 무한반복**

읽는 쪽: `관리도구/banner_remote.py`
